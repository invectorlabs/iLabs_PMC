◆ configurePmc()

uint8_t PMCClass::configurePmc ( uint8_t  divider,
enum pit_ctrl_clk  clk 
)

Configure the PMC device's timer system.

This method sets up the Peripheral Interval Timer (PIT) with the specified divider and clock source.This time base is used to internally run a 16 bit timer that determines the amount of time a system should sleep for. The PIT can be configured to run at either 32.768KHz or 1024Hz and have a prescaler that creates the time base. This prescaler (divider) can be configured in 14 steps as follows:

CLK / 4 CLK / 8 CLK / 16 CLK / 32 CLK / 64 CLK / 128 CLK / 256 CLK / 512 CLK / 1024 CLK / 2048 CLK / 4096 CLK / 8192 CLK / 16384 CLK / 32768

The sleep time can be derived from the following formula

t = sleep_timer / (freq / divider) 

freq={1024 | 32768}
Parameters
dividerThe prescaler divider value.
clkThe clock source for the timer (1024Hz or 32768Hz).
Returns
true if the command was sent successfully, false otherwise.

void PMCClass::readNVram ( uint8_t *  array,
uint16_t  offset,
uint16_t  len 
)

Read data from the non-volatile memory (NVM) of the PMC device.

This function reads a specified number of bytes from the NVM starting from a given offset. The data is read in chunks to accommodate the I2C buffer size limitations. The slave can transmit back 32 bytes max due to its internal buffer size. These 32 bytes does not include the command byte, addres and length information. This means when reading data we can receive 32 bytes of actual data in one frame. Anything more needs to be chunked up just like in the write case.

Parameters
arrayPointer to the data array where the read data will be stored.
offsetThe starting address in NVM from where the data should be read.
lenThe number of bytes to read from NVM.

◆ sleep()

uint8_t PMCClass::sleep ( double  seconds)

Put the PMC device to sleep for a specified duration.

This method configures the sleep timer and sends the sleep command to the PMC device. The system will enter sleep mode and will only wake up based on the configured wake-up sources or when the sleep timer expires.

Parameters
secondsThe duration in seconds for which the system should sleep.
Returns
This function does not return as the system enters sleep mode.
